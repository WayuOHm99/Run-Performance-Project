## 🟢 ใช้ทุกวัน — มีขั้นตอนเดียว

**พิมพ์บอก Claude ว่า:**

```
ดูของใหม่
```

จบ. Claude จะ:

1. รัน `day.py` ดึง **ตัวเลขจาก garmin.db** ของแต่ละคน (แทนการอ่านรูป)
2. อ่าน **RPE/ความรู้สึก/คำสั่งโค้ช** จากไลน์ (context.json + คำสั่งโค้ช.md)

> ถ้านักกีฬาเพิ่งวิ่งเสร็จแต่ยังไม่เปิดแอป ข้อมูลจะยังไม่มา (ไม่ใช่ระบบพัง)

## 🚨 เวลามีปัญหา

**ส่งรูปในไลน์แล้วแต่ไม่มีอะไรเข้ามา** → บอก Claude: `เช็คให้หน่อยว่าระบบรับข้อมูลปกติไหม`
สาเหตุที่เจอบ่อย: บอทถูกเตะออกจากกลุ่ม / สวิตช์ Use webhook ปิด / token ไลน์หมดอายุ

**Garmin ไม่อัปเดต / ข้อมูลค้าง** → เช็ค dashboard แท็บรวมทีม แถบ "sync ล่าสุด"
- 🔴 ค้างหลายวัน + มีแถบแดง "sync รอบล่าสุดล้มเหลว" → token เสีย ให้รัน `garmin\เพิ่มนักกีฬา.bat` ใหม่
- 🔴 ค้าง แต่ sync รอบล่าสุด**ผ่าน** (ไม่มีแถบแดง) → นักกีฬายังไม่เปิดแอป Garmin ให้นาฬิกา sync
- toast เด้ง "sync ล้มเหลว" → เปิด log ของสายนั้น `C:\Backup\garmin-sync-full.log` (รอบใหญ่ 08:00/21:00) / `-fast.log` (กิจกรรมทุก 15 นาที) / `-wellness.log` (ทุก 30 นาที)
- toast เด้ง "มีสายที่หยุดเดิน" → งานอัตโนมัติของสายนั้นไม่ได้รันมานาน เปิด Task Scheduler ดูว่างานยัง Ready อยู่ไหม แล้วรัน `scripts\setup_scheduled_tasks.ps1 -IncludeOptional` ซ้ำเพื่อซ่อมตารางงาน

**สคริปต์ขึ้น error สีแดง** → ก๊อปข้อความทั้งหมดมาให้ Claude อ่านและบอกวิธีแก้
