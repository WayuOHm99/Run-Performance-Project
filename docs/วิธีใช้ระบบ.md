## 👤 เพิ่มนักกีฬาใหม่

ดับเบิลคลิก `garmin\เพิ่มนักกีฬา.bat` → กรอกชื่อ (slug อังกฤษ) / อีเมล / รหัสผ่าน Garmin ของนักกีฬา
→ ได้ token ทันที (**รหัสผ่านไม่ถูกเก็บ**) แล้วรอบ sync ถัดไปจะดึงให้เอง

ถ้าไม่สะดวกขอรหัสผ่านตรง ๆ มีทางเลือกให้นักกีฬารันเอง (ดู `garmin\share\README_athlete.md`)

**สถานะปัจจุบัน:** ต้อง · แดน · พี่เก้า (มี token ครบทั้งทีม)
นาฬิกาต่างรุ่นให้ข้อมูลไม่เท่ากัน — พี่เก้ามีครบสุด ต้อง/แดนบางค่าเป็นค่าว่างตามรุ่นนาฬิกา

## 🚨 เวลามีปัญหา

**Garmin ไม่อัปเดต / ข้อมูลค้าง** → เช็ค dashboard แท็บรวมทีม แถบ "sync ล่าสุด"

- 🔴 ค้างหลายวัน + มีแถบแดง "sync รอบล่าสุดล้มเหลว" → token เสีย ให้รัน `garmin\เพิ่มนักกีฬา.bat` ใหม่
- 🔴 ค้าง แต่ sync รอบล่าสุด**ผ่าน** (ไม่มีแถบแดง) → นักกีฬายังไม่เปิดแอป Garmin ให้นาฬิกา sync
- **ตัวเลขบนจอไม่ขยับ** → กดปุ่ม "รีเฟรชข้อมูลล่าสุด" ก่อน หน้าจอไม่รีเฟรชเอง
- toast เด้ง "sync ล้มเหลว" → เปิด log ของสายนั้น: `C:\Backup\garmin-sync-full.log` (รอบใหญ่ 08:00/21:00) / `-fast.log` (กิจกรรมทุก 15 นาที) / `-wellness.log` (ทุก 30 นาที) / `-reconcile.log` / `-deepsync.log`
- toast เด้ง "มีสายที่หยุดเดิน" → งานอัตโนมัติของสายนั้นไม่ได้รันมานาน เปิด Task Scheduler ดูว่างานยัง Ready อยู่ไหม แล้วรัน `scripts\setup_scheduled_tasks.ps1 -IncludeOptional` ซ้ำเพื่อซ่อมตารางงาน

**สคริปต์ขึ้น error สีแดง** → ก๊อปข้อความทั้งหมดมาให้ Claude อ่านและบอกวิธีแก้
