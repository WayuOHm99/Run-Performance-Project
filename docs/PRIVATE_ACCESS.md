# เปิด Dashboard จากมือถือส่วนตัว — Tailscale (ไม่มีค่าใช้จ่าย ไม่เปิดสู่สาธารณะ)

ตรวจเอกสารต้นทางเมื่อ 30 ก.ย. 69 · ยังไม่ได้ทดสอบบนมือถือจริง (ต้องให้เจ้าของทำขั้นที่ 1–8 ก่อน)

## ภาพรวม

```
มือถือ/คอมที่อนุมัติแล้ว ──(tailnet เข้ารหัส)──> tailscale serve (HTTPS) ──> 127.0.0.1:8501 Streamlit ──> garmin.db (อ่านอย่างเดียว)
```

- Dashboard ฟังบน `127.0.0.1` เท่านั้น — เครื่องอื่นในวง LAN เดียวกันก็เข้าไม่ได้
- ไม่เปิด port forwarding ที่ router · ไม่ใช้ Tailscale **Funnel** (Funnel = เปิดสู่อินเทอร์เน็ตสาธารณะ ห้ามใช้กับข้อมูลนี้)
- ข้อมูลสุขภาพไม่ผ่านเซิร์ฟเวอร์ของ Tailscale ในรูปที่อ่านได้ (เข้ารหัสปลายทางถึงปลายทาง) และไม่ส่งไปบริการอื่น

## ค่าใช้จ่ายและเงื่อนไข (tailscale.com/pricing, tailscale.com/terms — ตรวจ 30 ก.ย. 69)

| หัวข้อ | ข้อเท็จจริง |
|---|---|
| แผน | Personal — **ฟรี** ผู้ใช้ได้ถึง 6 คน อุปกรณ์ไม่จำกัด |
| เงื่อนไข | สำหรับใช้ส่วนตัว ไม่ใช่เชิงพาณิชย์ · tailnet ที่ผูกกับ Gmail ได้แผนนี้อัตโนมัติ |
| ต้องตัดสินใจเอง | ถ้างานโค้ชเป็นงานรับเงิน อาจถูกตีความเป็นเชิงพาณิชย์ — ใช้เป็นเครื่องมือส่วนตัวของคุณคนเดียว (นักกีฬาไม่ได้เป็นผู้ใช้ tailnet) เป็นการอ่านเงื่อนไขที่ปลอดภัยที่สุด ถ้าไม่แน่ใจให้อ่าน terms เอง |

## ขั้นตอนที่คุณต้องทำเอง (ต้องใช้บัญชีและการยืนยันตัวตนของคุณ)

1. เปลี่ยนชื่อเครื่อง Windows เป็นชื่อกลาง ๆ ก่อน (เช่น `coach-pc`) — ชื่อเครื่องจะไปอยู่ใน Certificate Transparency log สาธารณะตอนออกใบรับรอง HTTPS
2. ติดตั้ง Tailscale บนคอมเครื่องนี้และบนมือถือ ล็อกอินด้วยบัญชีเดียวกัน (บัญชี Google ส่วนตัว) และเปิด **MFA** ของบัญชี Google นั้น
3. ใน Admin console → **DNS**: เปิด MagicDNS แล้วเปิด **HTTPS Certificates**
4. Admin console → **Settings → Device management**: เปิด **Device approval** แล้วอนุมัติเฉพาะคอมเครื่องนี้กับมือถือของคุณ
5. (แนะนำ) Access controls: จำกัดให้เฉพาะมือถือและคอมของคุณเข้าพอร์ต 443 ของคอมเครื่องนี้ได้
6. เปิด Dashboard ค้างไว้แบบไม่มีหน้าต่าง: ดับเบิลคลิก `garmin\tasks\dashboard-hidden.vbs`
   (ให้เปิดเองทุกครั้งที่ล็อกอิน: กด Win+R พิมพ์ `shell:startup` แล้ววาง shortcut ของไฟล์นี้ในโฟลเดอร์นั้น)
7. เปิด PowerShell แล้วสั่ง:
   ```
   tailscale serve --bg 8501
   tailscale serve status
   tailscale funnel status
   ```
   `serve status` ต้องขึ้นว่า **(tailnet only)** และ `funnel status` ต้องไม่มีอะไรเปิดอยู่
8. บนมือถือ **ปิด Wi-Fi ใช้เน็ตมือถือ** แล้วเปิด `https://<ชื่อเครื่อง>.<tailnet>.ts.net` — กดเปลี่ยนหน้าและเลื่อนวันที่ให้ดูว่าตัวเลขเปลี่ยนตาม

ถ้าหน้าเปิดได้แต่ค้าง/ขึ้น 403: ตั้ง `browser.serverAddress = "<ชื่อเครื่อง>.<tailnet>.ts.net"` ใน `garmin\.streamlit\config.toml` แล้วเปิด dashboard ใหม่ (ข้อนี้ยังไม่ได้ทดสอบจริง)

## หยุด / ถอนสิทธิ์

| ต้องการ | ทำอย่างไร |
|---|---|
| หยุดเปิดให้มือถือเข้า | `tailscale serve --https=443 off` หรือ `tailscale serve reset` |
| มือถือหาย | Admin console → Machines → เลือกมือถือ → **Remove** · ออกจากระบบ Google บนมือถือนั้นด้วย · ทดสอบซ้อมหนึ่งครั้งกับเครื่องสำรองว่าถอดแล้วเข้าไม่ได้จริง |
| หยุด Dashboard | ปิดโปรเซส `python.exe` ที่รัน streamlit (Task Manager) หรือรีสตาร์ตเครื่อง |

## ข้อจำกัดที่ต้องรู้

- เครื่องนี้เป็นโน้ตบุ๊ก (Modern Standby): ตอนเครื่องหลับ/ปิด ทั้งการ sync และการเปิดจากมือถือหยุดหมด เมื่อเปิดกลับมา Task Scheduler ตามเก็บรอบที่พลาดเอง (`StartWhenAvailable=True` ทุก task — ตรวจแล้ว 30 ก.ย. 69)
- Task ทั้ง 9 ตัวเป็นแบบ **Interactive** = ทำงานเมื่อคุณล็อกอินค้างไว้ (ล็อกจอได้) แต่ถ้า **Sign out** จะหยุด การเปลี่ยนเป็น "run whether user is logged on or not" ต้องเก็บรหัสผ่าน Windows ใน Task Scheduler — ยังไม่ทำ เพราะเป็นการเปลี่ยนสิทธิ์ระบบและยังไม่มีหลักฐานว่าคุณ sign out บ่อย
- ใบรับรองจาก `tailscale serve` มาจาก Let's Encrypt อายุ 90 วัน — การต่ออายุอัตโนมัติยังไม่ได้ยืนยัน ตั้งเตือนตัวเองให้เปิดเช็กราว 29 ธ.ค. 69
- คอมที่ปิดสนิทส่งแจ้งเตือนเรื่องการปิดของตัวเองไม่ได้ — heartbeat บน GitHub (`system_heartbeat.py`) คือตัวที่เห็นว่าเครื่องหายไป
