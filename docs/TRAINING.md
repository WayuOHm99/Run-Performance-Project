# กฎการเขียนตารางซ้อม (Training Plan Formatting Rules)

เมื่อ Claude Code เขียนตารางซ้อมให้กับนักกีฬาในทีม **ต้องใช้รูปแบบและภาษาต่อไปนี้** เพื่อรักษาเอกลักษณ์ของโค้ช

## 1. การใช้เกียร์ความเร็ว (working zones)

ให้ใช้คำศัพท์เฉพาะและ Emoji ต่อไปนี้ในการบอกโซนความเร็ว:

- **@RE (Recovery):** วิ่งเต่าคลาน 🐢
- **@E (Easy):** วิ่งชมนกชมไม้ 🕊️
- **@Sub-T (Sub-Threshold):** วิ่งสนุกๆ 🎵
- **@T (Threshold):** วิ่งแข่งกับเพื่อน 🏃‍♂️
- **@I (Interval):** วิ่งหนีหมาดุ 🐕
- **@R (Repetition):** วิ่งจรวดเดอะแฟลช 🚀

เพซของเกียร์ให้เริ่มจากผล race/time trial/lab ที่ระบุวันที่และวิธี แล้วตรวจซ้ำด้วย RPE/HR
และการทำได้จริงของนักกีฬา; VDOT เป็นโมเดลช่วยตั้งต้น ไม่ใช่ค่าจริงตายตัว. ถ้าผลเทสเก่า
หรือการตอบสนองไม่ตรง ให้เขียนเป็นช่วงเพซ+RPE และระบุสิ่งที่ต้องสังเกต แทนการบังคับเพซเดียว

## 2. โครงสร้างคำสั่งรายบุคคล (Daily Session Template)

คำสั่งในแต่ละวันสำหรับนักกีฬาแต่ละคน **ต้องแบ่งเป็นข้อๆ และมีการคั่นด้วย "- จิบน้ำ" เสมอ** ตามรูปแบบด้านล่างนี้:

```markdown
พรุ่งนี้ [ชื่อนักกีฬา] วิ่งเช้า (ตื่น) [เวลา เช่น 6-7โมงเช้า] ได้หมด
**@[ชื่อนักกีฬา]**
ทำตามลำดับ
1. ยืดเหยียดเคลื่อนไหว สบายๆ จังหวะเร็วเล็กน้อย (emotional)
- จิบน้ำ
2. ดริล 6 ท่าเบสิค จังหวะเบา-ปกติ (Cony hope)
- 2.1 เข่าต่ำ, 2.2 เข่าสูง, 2.3 เตะหน้า, 2.4 ดีดส้น, 2.5 A-skip, 2.6 เด้งข้อเท้า *ทำรอบเดียว*
- จิบน้ำ
3. วิ่ง [เกียร์ความเร็ว เช่น @E] เวลา [ระยะเวลา] / โฟกัส RPE [ระดับ RPE] หรือ ช่วงเพซ [เพซเป้าหมาย]
- จิบน้ำ
Finish
```

## 3. กฎเพิ่มเติม

- ภาษาที่ใช้เขียนต้องเป็นกันเอง (เช่น "น้อนแดน", "พี่เก้า", "คับ/ครับ")
- ท่าดริล/ยืดเหยียดเป็น template ที่ปรับตาม purpose, ประสบการณ์และอาการ; งด/ลดเมื่อเจ็บ
  เคลื่อนไหวผิดปกติ หรือเป็น recovery session ที่ไม่ต้องการโหลดเพิ่ม
- ห้ามปรับตารางจากนอนน้อย, HRV, EF, Body Battery หรือ Garmin Readiness ค่าเดียว. ก่อนส่งคำสั่ง
  ให้ถาม pain/illness, fatigue/soreness, sleep/stress/motivation, ดูเป้าหมายเซสชันและโหลดจริง
- ถ้ามีอาการเจ็บเฉพาะจุดจนฟอร์มเปลี่ยน ไข้/อาการป่วยทั้งตัว เจ็บหน้าอก เวียนหัว หรือหายใจผิดปกติ
  ให้หยุดการตัดสินด้วย dashboard และส่งต่อแพทย์/นักกายภาพตามความเหมาะสม
- ทุกงานหลักต้องบอก purpose, target (เพซ/HR/RPE ตามที่เหมาะ), stop/modify rule; หลังซ้อมให้ถาม
  completed dose, session RPE, pain/อาการ, สภาพอากาศ/พื้นผิวและ fueling เพื่อใช้ปรับครั้งถัดไป
