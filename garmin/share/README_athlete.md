# 📩 ขอ Token Garmin สำหรับทีม (ทำครั้งเดียว ~5 นาที)

สวัสดีครับ 🙏 เรากำลังรวบรวมข้อมูลซ้อม/สุขภาพจาก Garmin ของทีมมาดูภาพรวมด้วยกัน
รบกวนช่วยสร้าง "token" ให้หน่อย โดยทำตามนี้ (รหัสผ่านของคุณ **ไม่ถูกเก็บ** ที่ไหนทั้งสิ้น)

## สิ่งที่ต้องมี
- คอมพิวเตอร์ (Windows / Mac ก็ได้)
- **Python 3.12 ขึ้นไป** → ดาวน์โหลด https://www.python.org/downloads/
  - ตอนติดตั้งบน Windows **ติ๊กช่อง "Add Python to PATH"** ด้วย
- ไฟล์ `get_garmin_token.py` (แนบมาให้)

## ขั้นตอน
1. เอาไฟล์ `get_garmin_token.py` ไว้ในโฟลเดอร์ที่หาเจอง่าย (เช่น Desktop)
2. เปิดโปรแกรมพิมพ์คำสั่ง:
   - **Windows:** คลิกขวาในโฟลเดอร์นั้น → "Open in Terminal" (หรือเปิด PowerShell แล้ว `cd` เข้าโฟลเดอร์)
   - **Mac:** เปิด Terminal แล้ว `cd` เข้าโฟลเดอร์นั้น
3. พิมพ์คำสั่งนี้แล้วกด Enter:
   ```
   python get_garmin_token.py
   ```
   > ถ้า Windows ขึ้นว่าไม่รู้จัก `python` ให้ลอง `py get_garmin_token.py`
4. กรอกตามที่ถาม:
   - **ชื่อ** (ภาษาอังกฤษ เช่น `testohm`, `tong`)
   - **อีเมล** Garmin Connect
   - **รหัสผ่าน** (พิมพ์ไปเลย จอจะไม่โชว์ตัวอักษร — เป็นเรื่องปกติ)
   - ถ้าเปิด **MFA/2FA** ไว้ จะมีถามโค้ด → เปิดแอป/ดู SMS/อีเมลเอาโค้ดมากรอก
5. ถ้าสำเร็จจะได้ไฟล์ **`garmin_token_<ชื่อคุณ>.zip`** อยู่ในโฟลเดอร์เดียวกัน

## ส่งกลับ
ส่งไฟล์ `garmin_token_<ชื่อคุณ>.zip` กลับมา **ทางแชทส่วนตัวเท่านั้น** 🔒

> ไฟล์นี้ **ไม่มีรหัสผ่าน** ของคุณ แต่ใช้เข้าถึงข้อมูล Garmin ได้ จึงไม่ควรโพสต์ในกลุ่มสาธารณะ
> อยากยกเลิกสิทธิ์ทีหลังเมื่อไหร่ก็ได้ แค่เปลี่ยนรหัส Garmin หรือ sign out ทุกอุปกรณ์

## ติดปัญหา?
- **`python` ไม่ทำงาน** → ใช้ `py` แทน หรือเช็คว่าติดตั้ง Python แล้วและติ๊ก "Add to PATH"
- **`login บ่อยเกินไป / 429`** → รอ ~15 นาทีแล้วรันใหม่
- **โค้ด MFA ไม่ผ่าน** → รันใหม่แล้วกรอกโค้ดให้ไวขึ้น (โค้ดหมดอายุเร็ว)
- ติดตรงไหนทักถามได้เลย 🙌
